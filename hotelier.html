FAQ

The honest answers.

What is the stack?
Hotelier is built on Next.js and React with TypeScript, styled with Tailwind, and data handled through Prisma on Postgres. It deploys cleanly to Vercel, or anywhere that runs a Next.js app and a Postgres database.
What database does it need?
A Postgres database. Any provider works: Vercel Postgres, Neon, Supabase, Railway, or your own server. Schema and migrations are included, so you point it at a connection string and run the migration.
What does the license allow?
The Solo license covers one hotel that you run or build. The Agency license lets you build unlimited client hotels on Hotelier. Both are one-time purchases with free updates. Reselling Hotelier as its own product or white-label template is not included.
Do I need my own AI keys?
Yes. The AI concierge runs on your own model provider key, which you add as an environment variable. You stay in control of the model and the spend. The /prompts customization kit works with whichever AI editor you already use.
What support do I get?
You get the full source, setup documentation, the /prompts kit, and free updates. Support scope is setup and update guidance, not bespoke development. If you want custom work or a done-for-you build, that is a separate engagement with the studio.
Does it sync with Booking.com or Agoda?
No. Hotelier is a direct-booking system built to keep OTA commission in the house. There is no channel manager and no OTA sync out of the box. The code is yours, so you can wire those in yourself if you need them.
